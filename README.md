🛍️ More Fashions - E-commerce & Sistema de Usuarios
Proyecto web desarrollado para la gestión de usuarios, catálogo de moda femenina y autenticación con PHP y MySQL.

🛠️ Tecnologías utilizadas
Frontend: HTML5, CSS3 (Diseño responsive y personalizado).
Backend: PHP.
Base de datos: MySQL.
🚀 Funcionalidades principales
 Registro de usuarios con contraseñas encriptadas (password_hash).
 Inicio de sesión (Login) con manejo de sesiones activas.
 Interfaz adaptable para catálogo de productos.
